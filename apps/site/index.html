Waymark Launcher

A launcher for Minecraft: Java Edition that keeps a history of every instance, so a bad update can be undone. It runs every version back to the first build from 2009, and it searches five mod sites from one page.

Download for Windows

64-bit installer, about 6 MB. It updates itself after that.

Linux (AppImage and .deb) and macOS (Apple silicon and Intel) builds are on the latest release, along with a SHA256SUMS.txt to check any download against. The macOS builds haven't been tested on a real Mac.

You need the Microsoft account that owns Minecraft: Java Edition. The installer isn't code-signed, so Windows shows “Windows protected your PC” the first time: choose More info, then Run anyway. The code signing policy explains where signing stands.

History

Waymark Launcher records an instance's mods and config files whenever they change, and again before each launch. Each record is a waymark. Choose an earlier one and the instance goes back to that state. Only the files that differ are touched, so this is quick even on a large pack, and the state you left stays in the list in case you want it back.

Worlds aren't included. They're too large and change too often, and removing a mod shouldn't rewind your saves.

Each file is stored once, by hash, and hard-linked into the instances that use it. A second copy of a large modpack takes up almost no extra disk space, and a waymark is only a list of hashes.

Moving in

Waymark Launcher finds the instances in Prism Launcher, MultiMC, ATLauncher, GDLauncher, the CurseForge app, the Modrinth App and the Minecraft Launcher, and offers to copy them over with their worlds, mods, settings and time played. Importing makes a copy and leaves the original alone. From the Minecraft Launcher it copies game files only, never its sign-in.

Starting fresh, a preset sets up an instance for what you want to play: performance, PvP, shaders, building, speedrunning practice or a big adventure modpack. Each preset uses the newest build of every mod that fits the Minecraft version you pick, and tells you which ones don't have one.

Every version

Mojang's launcher lists 61 versions from before 1.0. Waymark Launcher adds 215 builds it leaves out, and reaches back to RubyDung from May 2009. That covers Pre-Classic, Classic, Indev, Infdev, Alpha, Beta, the snapshots in between, Minecraft 4k and the 2.0 April Fools builds. Pick an era when you make a new instance.

The list comes from BetaCraft, most of the recovered builds were found by Omniarchive, and BetaCraft's LegacyFix brings back the skins, sound and multiplayer sign-in these versions lost. Waymark Launcher hosts none of the game files, and each one is checked against a known hash before it runs.

Crashes

After a crash, Waymark Launcher reads the crash report and latest.log on your computer and looks for known causes: a mod built for a newer Java, a missing dependency, two copies of one mod, a Mixin failure, running out of memory, or a graphics driver fault. If it recognizes one, it tells you which mod is involved and what to change.

When the log doesn't say why, Waymark Launcher can search for the cause. It switches half the mods off, keeping their dependencies on, and asks you to launch the game and report what happened. Then it repeats with whichever half is left. A 300 mod pack takes about a dozen launches, and a crash that needs two mods loaded together turns up both.

Updates

Waymark Launcher checks every Modrinth mod in an instance with a single request and applies the updates as one change, so one rollback undoes all of them. CurseForge mods are checked the same way. You can read each changelog and pick a version first.

New releases are held back for 48 hours by default. In 2023 the Fractureiser malware spread through stolen CurseForge and Bukkit accounts, and a short delay gives people time to catch something like that before it reaches your game. You can change the delay or turn it off.

On Windows, Waymark Launcher then starts the game on a hidden desktop to see whether it still loads, so a check can't pull you out of whatever you're doing. If the update stopped the game from starting, Waymark Launcher undoes it and tells you why. Pressing Play ends the check, and you can turn checks off in Settings.

Finding things to install

Discover searches Modrinth, CurseForge, Feed The Beast, ATLauncher and Technic from one page, with filters for Minecraft version, loader and category. It covers mods, modpacks, shaders, resource packs and data packs, and marks what you already have.

The Servers page lists the Java servers their owners publish on Modrinth, with filters and live player counts. Join sets up the right instance the first time, down to the exact modpack version a modded server uses, and after that Play goes straight into the server.

Friends

Friends are optional and use a separate Waymark Launcher account: a username and a password, with no email address. You can see who's online and what they're playing, send them an instance, and let them join a server you host from Waymark Launcher. Letting friends join asks your router to open a port and shows them your internet address, so it stays off until you turn it on.

A forgotten password can't be recovered, because there's no email to send a reset to. The privacy policy lists what the friends server keeps.

Requirements

You need a Microsoft account that owns Minecraft: Java Edition. Waymark Launcher checks ownership when you sign in and again at every launch, and the game won't start without it. There is no username-only mode. With no internet connection, an account verified in the last 30 days can still play.

Minecraft is downloaded from Mojang's servers and isn't redistributed. Sign-in tokens are kept in Windows Credential Manager and are only sent to Microsoft and Mojang.

About this project

Waymark Launcher is made by one person, Woblu, who started it in October 2026 and is responsible for it. It's young, so expect rough edges, and please report them on GitHub.

It's written with a lot of help from Claude, an AI model made by Anthropic. Woblu decides what goes in and tests each release on Windows and Linux before publishing it. The core has over 360 automated tests, and an end-to-end test drives the real app the way a player would.
