Waymark

A launcher for Minecraft: Java Edition that keeps a history of every instance, so a bad update can be undone.

Download Waymark for Windows, about 6 MB. It updates itself after that.

You can install Waymark and look around today, but you can't play yet. Mojang is still reviewing it for Minecraft sign-in, and the game won't start without that. Windows will also warn you about an unknown publisher, because the installer isn't code signed yet.

History

Waymark records an instance's mods and config files whenever they change, and again before each launch. Each record is a waymark. Choose an earlier one and the instance goes back to that state. Only the files that differ are touched, so this is quick even on a large pack, and the state you left stays in the list in case you want it back.

Worlds aren't included. They're too large and change too often, and removing a mod shouldn't rewind your saves.

Each file is stored once, by hash, and hard-linked into the instances that use it. A second copy of a large modpack takes up almost no extra disk space, and a waymark is only a list of hashes.

Finding a bad mod

When a pack crashes and the log doesn't say why, Waymark can search for the cause. It switches half the mods off, keeping their dependencies on, and asks you to launch the game and report what happened. Then it repeats with whichever half is left.

A 300 mod pack takes about a dozen launches. If a crash only happens when two mods are loaded together, the search finds both.

Crash reports

After a crash, Waymark reads the crash report and latest.log on your computer and looks for known causes: a mod built for a newer Java, a missing dependency, two copies of one mod, a Mixin failure, running out of memory, or a graphics driver fault. If it recognizes one, it tells you which mod is involved and what to change.

Updates

Waymark checks every Modrinth mod in an instance with a single request and applies the updates as one change, so one rollback undoes all of them. CurseForge mods are checked the same way. You can read each changelog and pick a version first.

New releases are held back for 48 hours by default. In 2023 the Fractureiser malware spread through stolen CurseForge and Bukkit accounts, and a short delay gives people time to catch something like that before it reaches your game. You can change the delay or turn it off.

Finding things to install

Discover searches Modrinth, CurseForge, Feed The Beast and ATLauncher from one page, with filters for Minecraft version, loader and category. It covers mods, modpacks, shaders, resource packs and data packs, and marks what you already have.

Worlds and servers

Each instance lists its worlds and servers. On Minecraft 1.20 and newer, Play on a world or server goes straight there without the menus. Deleted worlds stay in a trash folder for 30 days.

Waymark can also build a server from an instance and run it on your computer. Mods that only work on the client are left out. It stops at the Minecraft EULA until you accept it yourself.

Skins

Try on any skin on a 3D model before you wear it. Waymark keeps a library of your own PNG files alongside the skins Minecraft comes with.

Friends

Friends are optional. They use a separate Waymark account, which is a username and a password with no email address. You can see who's online and what they're playing, and send them an instance. Only store ids travel, never the files.

The server keeps your username, a hash of your password, your friends list, anything sent to you, when you were last online and the name of the instance you're playing. You can hide your status, block people, or delete the account and all of that from the app. A forgotten password can't be recovered, because there's no email to send a reset to.

Updating Waymark

New versions download in the background and install when you close the app, or sooner if you choose Restart to update. Each one is signed, and Waymark refuses anything that doesn't match. It never updates during a game or while it's hosting a server. You can turn this off in Settings.

Requirements

You need a Microsoft account that owns Minecraft: Java Edition. Waymark checks ownership when you sign in and again at every launch, and the game won't start without it. There is no username-only mode. With no internet connection, an account verified in the last 30 days can still play.

Minecraft is downloaded from Mojang's servers and isn't redistributed. Sign-in tokens are kept in Windows Credential Manager and are only sent to Microsoft and Mojang.
