Waymark Launcher

Code signing policy

Signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows installers are built by GitHub Actions from the public source in Woblu/waymark-launcher, and nowhere else. A signature means the file is the one that build made, unchanged. Every release is approved by hand before it's signed.

Waymark Launcher also signs its own updates with a separate key, so an installed copy only accepts updates from this project.

Team

Committers and reviewersWoblu
ApproversWoblu

Committers can change the source. Every change from anyone else, such as a pull request, is reviewed by a committer before it's merged. Approvers decide whether a release gets signed.

Privacy

Waymark Launcher connects to Minecraft's services and the mod stores to do what you ask, and checks for its own updates, which you can turn off. The privacy policy lists every service it talks to, what each one sees, and the policies of those services.

Installing and removing

The installer puts Waymark Launcher in your user folder, adds it to the Start menu and to Apps in Windows Settings, and installs Microsoft's WebView2 runtime if Windows doesn't have it yet. It changes no other system settings. Remove Waymark Launcher from Windows Settings, under Apps. Your instances stay in %APPDATA%\Waymark Launcher until you delete that folder.
