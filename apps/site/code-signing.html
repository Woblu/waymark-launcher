Code signing policy

Signing

Status, November 2026: Waymark Launcher has applied to the SignPath Foundation for free code signing and is waiting for an answer. Today's installers aren't code-signed, and Windows warns about an unknown publisher. The rest of this section is the policy signed releases will follow.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Windows installers are built by GitHub Actions from the public source in Woblu/waymark-launcher, and nowhere else. A signature will mean the file is the one that build made, unchanged. Each release will be approved by hand before it's signed.

Separately from that, Waymark Launcher already signs its own updates with a key of its own, and an installed copy only accepts updates signed with it.

Committers can change the source. Every change from anyone else, such as a pull request, is reviewed by a committer before it's merged. Approvers decide whether a release gets signed.

Privacy

Waymark Launcher connects to Minecraft's services and the mod stores to do what you ask, and checks for its own updates, which you can turn off. The privacy policy lists every service it talks to, what each one sees, and the policies of those services.

Installing and removing

The installer puts Waymark Launcher in %LOCALAPPDATA%\Waymark Launcher, adds it to the Start menu and to Apps in Windows Settings, and installs Microsoft's WebView2 runtime if Windows doesn't have it. It changes no other system settings.

Remove Waymark Launcher from Windows Settings, under Apps. Your instances and settings stay in %APPDATA%\Waymark until you delete that folder. To remove your sign-ins too, sign out of each account in Waymark Launcher before uninstalling, or delete the entries ending in app.waymark.launcher under Windows Credentials in Credential Manager.
