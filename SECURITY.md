# Security

## Reporting a problem

Please report security problems privately, through GitHub's [private vulnerability reporting](https://github.com/Woblu/waymark-launcher/security/advisories/new) or by email to waymarklaunchersupport@proton.me, and not in a public issue.

You'll get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather not be named.

## Supported versions

Only the newest release gets fixes. Waymark Launcher updates itself, so most players have a new release within a day.

## What to report

Anything that lets someone else run code on a player's computer, read a player's sign-in, or play without owning the game. For example:

- a modpack, share code or store page that can write outside its instance, run a command, or run a script inside the app
- an update that installs without a valid signature
- a way to read or change another player's friends data
- a sign-in token sent anywhere other than Microsoft, Xbox Live and Mojang

Problems in Minecraft, in a mod or in a mod store belong with that project.
